## 二、三个硬坑（实测）

### 坑 1：`wrap()` 只认空格，中文永不换行

`src/engine/draw.js:181`

```js
for (const word of para.split(' ')) { ... }   // 一个空格都没有的中文，整段就是一个 word
```

实测：七十字的问题打进输入框，整句一路冲出右侧边框，直接切进画面外的黑边（`out\zh_wrap.png`）。不是裁切问题，是压根没换行。

修法：按字断行 + 避头尾（`，。、？！：；）】` 不许落行首，`（【` 不许落行尾）。

### 坑 2：`mono` 的汉字宽度按 0.6 em 算

`src/engine/draw.js:160`

```js
if (font === 'mono') return str.length * (size * 0.6 + spacing);   // JetBrains Mono 的等宽度量
```

汉字是 1 em 方块，按 0.6 算出来全部缩水四成。代码窗口、系统提示、命令行那一片全走 mono，中文一进去，居中、描边、光标、裁切全歪。

修法：mono 路径按字符判定，CJK 记 1 em、拉丁记 0.6 em。

### 坑 3：字白名单，漏一个字就回落系统字体

`src/engine/draw.js:199-206` + `src/engine/engine.js:42`

CJK 角色只预加载 `text` 里列出的字，别的字会报错并悄悄回落到系统字体（每台机器字形不同）。实测日志：

```
[text] glyph outside the preloaded text of 'tcSans' in "你会怎么爱我，如果你只会算数，..."
- only "中文本片含有...你会怎么爱我，如果你只会算数，而我是那个算不出的数。" is loaded for it
  (U+5728 U+7B2C U+4E03 U+6B21 U+5D5D ...)
```

一句七十字的词，带出二十多个漏网的字。**这条最阴**：不报错时看不出，报错时画面已经画歪了。

修法：把族名换成字体栈（`"Noto Sans SC", "Inter"`），浏览器按字符自己挑字体，白名单机制作废，中英混排天然正确。

### 附带两条

- `typing.charsPerSec: 26` 是英文速度，中文一字一句，26 字/秒是子弹，得降到 12–15
- 已装的 CJK 包只有 TC / KR 变体，没有简体（SC）。简体字形在 TC 字库里大多有，但写法是台湾标准。要标准简体得 `npm i @fontsource/noto-sans-sc @fontsource/noto-serif-sc`

## 三、下一步方案（三处改动，全片一次生效）

| 改哪 | 改什么 |
|:--|:--|
| `draw.js → font()` | `"${family}"` 改成字体栈，每族带上 CJK 后备 |
| `draw.js → wrap()` | 加按字断行 + 避头尾，英文路径不变 |
| `draw.js → measure()` | mono 的 CJK 字宽按 1 em |
| `config.json → fonts` | 加 `zhSerif` / `zhSans` 两个简体 role |
| `config.json → typing` | `charsPerSec` 26 → 12~15 |

改完之后 **15 个场景文件一行都不用动**，因为场景里写的都是 role 名（`serif`/`sans`/`mono`），栈在底层展开。

风险：`wrap()` 是共用的，改它要回归英文排版（标题、气泡、代码窗口）。验法是拿原版对照分镜表逐段比。

## 五、落地记录（2026-11-16，第二轮，本文所有结论都已在本机跑过）

### 1. 字体层：三坑全修

| 坑 | 位置 | 修法 |
|:--|:--|:--|
| `wrap()` 只认空格 | `src/engine/draw.js` | 段落含 CJK 时按字断行（拉丁词不拆、行首去空格、行尾 trimEnd），再跑两遍避头尾：`NO_HEAD` 不许落行首（，。、？！：；）》】）、`NO_TAIL` 不许落行尾（（【《「） |
| `mono` 汉字按 0.6 em | `src/engine/draw.js` | `measure()` 的 mono 分支改成逐字累加 `adv()`：CJK 1 em、拉丁 0.6 em |
| 字白名单只认拉丁 | `src/engine/draw.js` / `src/engine/engine.js` | 三个 role 的族名改成字体栈 `"拉丁族","CJK 族",generic`；`text()` 校验分两类：拉丁角色可借用 ≥ 其 CJK 后备已预载的字，CJK 角色仍只认自己的 `text` |

- 字体包：`npm install --prefix ".\assets\fonts" @fontsource/noto-sans-sc @fontsource/noto-serif-sc`，装到 `assets\fonts\node_modules`。**刻意不写原工程的 `node_modules`**（那是 Junction，指向上游）。
- `engine.js → loadFonts`：CJK 条目支持 `weights:[...]` 与 `base`（自定义 CSS 目录，逐段 `encodeURIComponent`）；每字重单独 link CSS，再 `document.fonts.load(\`${w} 64px "${family}"\`, text)`，没有 face 直接抛错。导出 `cjkWeights`，`loadSteps` 按字重数量计数。

### 6. 仍未做 / 新发现

> 跨层的坑与工作法集中记在 `二次创作\说明\踩坑与经验.md`；这一节只留中文化相关。
- **美术层八张剪影**：图仍未换，是原片 CC BY-NC-SA 素材，发出去前必须换。**生图不由接管方负责**（作者/画师出图），接管方只做接线与验收；已交付两件不依赖出图的东西：
  - `二次创作\说明\剪影规格.md`：画师照做的一张单子，含八张实测（尺寸、包围盒、留白、三墨实测值、alpha 残点）、七条硬规格、每张用途与秒数、可选扩展图命名、交付流程、验收清单。
  - `tools\art_check.mjs`：无 PNG 解码库，所以借工程自带的 playwright + `export\server.mjs` 静态服务在无头浏览器里解码。逐张量尺寸 / alpha 构成 / 三墨实测与「三墨外像素占比」/ 包围盒与四边留白，并与 `docs/v4/art/baseline.json`（当前八张的实测基线）比构图位移与尺度。`--baseline` 重写基线，`--json out/art.json` 出数据，`--strict` 规格不符即非零退出。当前八张跑通：0 项必须处理、38 条规格提醒（长边不足、残点、alpha 非 255、最小留白 0–1%、三墨外 1–2%）。
  - 接入（`regions.json` 标定、`REGISTER` 表、`loadSteps` 计数）等图到位后再动，避免用旧图标定的数值假通过。
  - SVG 路线已验：`--artsvg` 可吃矢量图，`tools\raster_to_svg.mjs` 能把三墨 PNG 转成 SVG；但现有素材矢量化无画质收益（同尺寸 PSNR 37.4 dB），且源尺寸一变构图就错（PSNR 11 dB）——因为场景把 1086×1448 当设计单位写死。结论与清单见剪影规格单第七节。
- **整片导出**：本机 ffmpeg 4.2.2 不认 `adelay=...S:all=1`（`all` 选项不存在），带 5 秒 preroll 的导出会直接失败。已改成按声道给值 `adelay=220500S|220500S`（`export\export.mjs`），`--start -5 --end 0 --width 1280 --height 720 --fps 30`（150 帧 / 5 秒 / 12.8 MB）验证通过。**这跟中文化无关，是上游写法与本机 ffmpeg 版本不合。**
