## 二、三个硬坑（实测）

### 坑 1：`wrap()` 只认空格，中文永不换行

`src/engine/draw.js:181`

```js
for (const word of para.split(' ')) { ... }   // 一个空格都没有的中文，整段就是一个 word
```

实测：七十字的问题打进输入框，整句一路冲出右侧边框，直接切进画面外的黑边（`out\zh_wrap.png`）。不是裁切问题，是压根没换行。

修法：按字断行 + 避头尾（`，。、？！：；）】` 不许落行首，`（【` 不许落行尾）。

### 坑 2：`mono` 的汉字宽度按 0.6 em 算

`src/engine/draw.js:160`

```js
if (font === 'mono') return str.length * (size * 0.6 + spacing);   // JetBrains Mono 的等宽度量
```

汉字是 1 em 方块，按 0.6 算出来全部缩水四成。代码窗口、系统提示、命令行那一片全走 mono，中文一进去，居中、描边、光标、裁切全歪。

修法：mono 路径按字符判定，CJK 记 1 em、拉丁记 0.6 em。

### 坑 3：字白名单，漏一个字就回落系统字体

`src/engine/draw.js:199-206` + `src/engine/engine.js:42`

CJK 角色只预加载 `text` 里列出的字，别的字会报错并悄悄回落到系统字体（每台机器字形不同）。实测日志：

```
[text] glyph outside the preloaded text of 'tcSans' in "你会怎么爱我，如果你只会算数，..."
- only "中文本片含有...你会怎么爱我，如果你只会算数，而我是那个算不出的数。" is loaded for it
  (U+5728 U+7B2C U+4E03 U+6B21 U+5D5D ...)
```

一句七十字的词，带出二十多个漏网的字。**这条最阴**：不报错时看不出，报错时画面已经画歪了。

修法：把族名换成字体栈（`"Noto Sans SC", "Inter"`），浏览器按字符自己挑字体，白名单机制作废，中英混排天然正确。

### 附带两条

- `typing.charsPerSec: 26` 是英文速度，中文一字一句，26 字/秒是子弹，得降到 12–15
- 已装的 CJK 包只有 TC / KR 变体，没有简体（SC）。简体字形在 TC 字库里大多有，但写法是台湾标准。要标准简体得 `npm i @fontsource/noto-sans-sc @fontsource/noto-serif-sc`

## 三、下一步方案（三处改动，全片一次生效）

| 改哪 | 改什么 |
|:--|:--|
| `draw.js → font()` | `"${family}"` 改成字体栈，每族带上 CJK 后备 |
| `draw.js → wrap()` | 加按字断行 + 避头尾，英文路径不变 |
| `draw.js → measure()` | mono 的 CJK 字宽按 1 em |
| `config.json → fonts` | 加 `zhSerif` / `zhSans` 两个简体 role |
| `config.json → typing` | `charsPerSec` 26 → 12~15 |

改完之后 **15 个场景文件一行都不用动**，因为场景里写的都是 role 名（`serif`/`sans`/`mono`），栈在底层展开。

风险：`wrap()` 是共用的，改它要回归英文排版（标题、气泡、代码窗口）。验法是拿原版对照分镜表逐段比。
