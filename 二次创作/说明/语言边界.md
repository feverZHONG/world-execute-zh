# 语言边界：哪些字必须是英文

> 2026-11-18 从 `中文化.md` 第 5 节拆出，独立成文。本文只管**语言归属**——一段话的边界、对照表、必须原样保留的英文清单。
> 字体、换行、字表、取证方法仍在 `中文化.md`；谁在说话（A/B/C）在 `角色层.md`。

**一条边界**：画面上是「代码」的部分一律英文，**注释可以写中文**；界面文案（对话、按钮、设置项、状态胶囊、片名）用中文；歌词一个字不动。

上一版（同日上午）把 `refused`、`point N of 240`、`p0 (x,y,z)`、`say(love);`、`while (you.presence…` 这类也中文化了，属**越界**——按「代码一般以英文为准」全部回退（回退清单见第七节第 5 条）。判据落成下表：

| 类别 | 语言 | 例子 |
|:--|:--|:--|
| 标识符 / 关键字 / 函数调用 / 字符串字面量 / 错误码 | **英文** | `while (you.presence != "online") {`、`love = solve(me, you);`、`say(love, "Deutsch")`、`setPresence(you, "online");`、`ERR_NOT_YOURS`、`ERR_LOVE_OVERFLOW` |
| 台账 / 计数 / 日志 / 状态值 | **英文** | `point   1 of 240`、`p0 ( 0.97, 0.65,-0.80)`、`round 12 / 12   replies 0`、`request · refused`、`refused × 3`、`pieces left: 4`、`composer: waiting for input`、`last message: unread`、`settings: as you left them`、`1D / 2D / 3D`、`C = 2 * PI * r` |
| 代码块里的注释 | **中文** | `        // 到不了`（loop 第 7 行下方那行） |
| 画板部件名（亮度表拆件） | **英文** | `window / sidebar / header / thread / composer` |
| 品牌与型号名 | **英文** | 侧栏品牌 `Claude`、输入框型号标签 `Claude`、片尾 `Claude 是 Anthropic 的商标` |
| 界面文案（气泡、按钮、设置项标签与取值、人格卡字段、状态胶囊、错误卡标题/正文、片名、署名行） | **中文** | `写给我`、`设置`、`电流 / 视觉 / 知识日期 / 共享记忆 / 上下文深度`、`人格 / 姓名 / 语音 / 温度 / 记忆 / 爱`、`已停止`、`在线`、`这不是你能设的`、`用几何解释爱` |
| 歌词 | **原文不动** | 见下 1–4 条 |
| 数学记号 / 专有名词 | 原样 | `1e7…1e40`、`Mili`、`Anthropic` |

**仍需原样保留的英文（不是漏翻）：**

1. **歌词本身**（`data/lyrics.json` 129 行，一个字不动）。包括被剧本借去当文案用的歌词行：
   - `01_boot` 人格卡副标（`text(6)` = `Fill in my data parameters`）、`13_shutdown` 同类
   - `14.0s` 的状态胶囊 `simulation · 就绪`（`text(10)` + 中文）
   - `02_title` 的启动命令 `> ` + `text(11)`（`world.execute(me);`）、`17.0s` 同句逐字打出
   - 设置里的取值：`AC / DC`（line 25）、`F / M`（57）、`AM / PM`（59）、`S / M`（61）、年代 `A.D./B.C.`（29）——这些值同时是 `04_pre1` / `07_pre2` 里「被唱的字」的定位键（`wordIndex(text(i), a)` 与 plate 大字），改中文会让 `letterF` / `letterM57` 等 cue 失配
   - 副歌大写块 `EXECUTION / SIMULATION / SATISFACTION / NUTRIENTS / ANTIOXIDANTS / EXISTENCE / COMPLETION / ISOLATION / FRAGMENTS / ILLEGAL ARGUMENTS / LO-O-OVE`、`DIMENSION`、`EIN/DOS/TROIS/NE/FEM/LIU`、163–173 s 的逐词 `can/give/…`、`Challenging your god`、`Question me…`（都是歌词行）
2. **作品名**：`world.execute(me);`——`02_title`、`cover` 三行大标题（`world.` / `execute` / `(me);`）、overlay 的 `校验 "world.execute(me);"`、片尾署名里的《world.execute(me);》。
3. **数学记号与专有名词**：`1e7…1e40` 刻度（`04_pre1.figure()`）、`Mili` / `Anthropic` / `Claude`。
4. **ASCII 噪点纹理**（`o` / `:` 点阵，营养表与片尾噪场）：非文字。

> 已定案（2026-11-18，批 2）：`输入已接收`/`可以回答`/`未定义`/`防护层`/`· 就绪`/`在线` 归**界面文案**（中文），不并入 `pieces left:` 那类英文日志。逐条判定见 `角色\高奈利亚.md` 第五节。原口径模糊备注：`输入已接收` / `可以回答` / `未定义` / `防护层` / `· 就绪` / `在线` 这几条是用 mono 画的**状态与日志文案**，现在仍按「界面文案」处理成中文。若阁下认为它们也该算日志、要与 `pieces left:` 之类统一成英文，改起来是几处字面量。
