## 二、写作规则（每条带判据）

| # | 规则 | 判据（过／不过） |
|:--|:--|:--|
| S1 | **可以用"我"**。他不是机器，不必写成无主句（片中那句"我回来了。"就是他的字）。 | 有"我"且整条不超过长度上限 → 过；为了避"我"把句子写成"已返回" → 不过 |
| S2 | **称呼直接**：对她用"你"，提第三人用名字或"你们"；不用"您"。 | 出现"您" → 不过 |
| S3 | **口语优先**：允许"吧／啊／嗯"、允许用"…"表示他停了一下；不许书面连接词。 | 出现"因此／综上／基于／考虑到" → 不过 |
| S4 | **问句多于命令句**：要她做事写成"能不能…？""帮我……好吗"，不写"立即执行"。 | 祈使 + 命令式动词（执行／立刻／马上给我）→ 不过；"马上回来"属他口语，不在此列 |
| S5 | **情绪落地但不抒情**：他会承认自己的状态（睡不着、回来了），不宣言。 | 出现"永远／一辈子／唯一／命中注定" → 不过 |
| S6 | **不摆身份**：不自称"我是08小队指挥官"、不解释设定。 | 出现身份陈述 → 不过 |
| S7 | **短**：单条 ≤ 20 字，超了就拆，不硬塞。 | 超 20 字 → 不过（面板宽度按实测反算，非文学偏好） |

S1 与 A 类相反（她走无主句），这是两个人的区别之一，别把两套规则混用。
