# 交图清单（给画师 / 给作者自己画）

这是 `剪影规格.md` 的一页纸版：**照着这张交，图放进 `assets/character/` 就能直接用，接线零改动。**
细节依据（实测值、三墨取样、HTML 怎么分墨）都在 `剪影规格.md`，这里只列"要准备什么"。

| `f_reach.png` | 一手伸出、一手抚胸，闭眼 | 3:4 | 3258×4344 | 3000 长边 | 副歌一 66–69；**手的特写 170.19**；最后一帧 |
| `f_eye.png` | 脸部特写，睁一只眼 | **1:1** | 3000×3000 | 2508×2508 | 124.89 / 161.88 / 162.81 / 166.50（全是特写） |

**`f_reach` 与 `f_eye` 一定有特写**（170.19 的手、124.89 起的眼部），这两张的清晰度直接决定成片观感；其余六张也都会被放大到 1080p 画面里（有的还会被推到近景），所以统一按 2× 交最省事——小图在近景里第一眼就糊。

> 尺寸为什么是 2172×2896：设计基准是 1086×1448，这一档正好 **2×**，整片算"清晰但不浪费"；再大只会变慢。比例必须是 3:4（`f_eye` 1:1），比例一变，片子里每一处裁切都会被拉扁，这不是渲染器能兜的。

## 二、硬规格四条（违反就一定返工）

1. **PNG-24 + alpha，sRGB，无 ICC**。不要 JPG、不要 WebP、不要预乘 alpha。
2. **只有三墨**：`#f4e0c6`（米白）/ `#dc723f`（橙）/ `#241a15`（近黑），每通道容差 ±12。
   不要渐变、不要半透明色块、不要第四种颜色（尤其别在橙与黑之间插一个"锈色"）、不要高光点、不要描边线。
3. **透明底干净**：主体 `alpha=255`，主体外 `alpha=0`；只允许 1–2 px 抗锯齿过渡，且过渡带内 alpha ≥ 200。
   不要毛边、发光、投影、噪点、纸纹。
4. **不裁切**：上、左、右各留 ≥ 长边 5% 空；**底边例外**——胸像在底边切齐（切点落在最后一行内），不要悬空。

**配准（这条最容易漏）**：同一个人/同一组形象的所有图，**下巴、发间花饰、领口三点落在同一坐标、同一大小**，以 `f_bust` 为准。`cat_bust` 现在几乎能直接重合；`boy_bust` / `man_bust` 旧图要缩 0.89 / 0.873 才能对上——**请直接画成能重合的尺寸，让那张校正表可以删掉**。

## 三、可以不准备的（省时间）

- **不用切图**：引擎自己在载入时分三墨、描轮廓、建遮罩。交一张合成的三色 PNG 就够。
- **不用分墨层**：能交 `_cream/_orange/_black` 三张分墨 PNG 会更干净（错版特效好看些），但**不给也不影响使用**。
- **不用转 SVG**：交 PNG 即可。若你更想交矢量，见 `剪影规格.md` 第七节五条（只许填充路径、比例配准不变、viewBox ≥2× 设计基准）。
- **不用做动效/不同表情**：表情、姿态是**另外的图**（见下"加分项"），不是同一张图里的图层。
- **不用管接线**：名字对了，图进片就自动生效；场景引用与 `REGISTER` 校正表是接管方的活。
- **不用重做 `regions.json`**：只要构图与旧图一致（同样的取景、同样的留白、同样的配准），这份标注文件继续有效。

## 五、交来之后我会做什么（你也照着自查一遍）

```powershell
node tools/art_dims.mjs                 # 尺寸 / 比例 / sx·sy 换算 / 载入告警（应为 0）
node tools/art_check.mjs                # 尺寸·alpha·三墨·留白·与旧图的构图位移与尺度差
node export/export.mjs --sheet out/new_art_45.png --times 45.4 --cols 1 --width 1280 --height 720
node export/export.mjs --sheet out/new_art_170.png --times 170.19 --cols 1 --width 1280 --height 720
```

判读口径：`art_check` 出现「必须处理」= 构图位移或尺度差 >5%，要退回改；只有「提醒」= 可用但要眼睛看。
两张静帧里看三件事：缩小到 720p 时睫毛/发丝是否糊成一片；橙块与米白块的分配是否还读得懂「她」；黑墨是否和页面底色糊在一起（黑墨几乎等于底色，每个用法背后都得有纸色或光托着）。
