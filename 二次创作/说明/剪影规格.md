## 二、交付硬规格

每一条都会在 `tools/art_check.mjs` 里被量出来，规格不符会被标红。

1. **格式**：PNG-24，带 alpha 通道，无 ICC 配置（sRGB 即可）。不要 JPG、不要 WebP、不要带预乘 alpha。
2. **解析度**：胸像类长边 **≥ 2000 px**；会做特写的（`f_eye`、`f_reach`、单张的手）长边 **≥ 3000 px**。画布比例沿用现有分组：胸像类 **3:4 竖幅**（七张都是 1086×1448），脸部特写 **1:1**（`f_eye` 是 1254×1254）。同组图的比例必须一致，否则硬切会跳。
3. **透明底要干净**：主体内外都要干净——主体 **alpha=255**，主体以外 **alpha=0**；墨与墨、体与底之间的抗锯齿只允许 1–2 px 的过渡带，且过渡带内 alpha 也要落在 200 以上（不要画成半透明玻璃）。手动画的毛边、发光、投影一律不要。
4. **严格三墨**：只用上面三个色值，**每通道容差 ±12**。不要渐变、不要半透明色块、不要第四种颜色、不要高光点、不要描边线。原图 `f_reach` 里有一种偏锈的色（在橙与黑之间），现在靠分墨硬折叠进黑色，请不要再出现。
   - **例外：七阶**。若一张图画不出三墨、只能靠现成素材过滤镜（见归档记录），可以按**第七节的七阶表**交付：仍是硬边平涂、透明底、每个色值都有准值，只是每族多一个暗面。三墨与七阶在引擎里都认，**艺术上三墨更贴近原片**，能三墨就三墨。
5. **不裁切、四边留白**：上、左、右三边各留 **≥ 长边的 5%** 空。**底边是例外**：胸像允许在一条水平线上切齐（现有八张都是切齐的），但请把切点放在文件底边一行内，不要留一半悬空。
6. **同组配准**：同一个人/同一组形象的图，下巴、花饰、领口必须落在**相同坐标**、大小一致。基准是 `f_bust`（1086×1448）：以它的下巴、发间花饰、领口三点为准，其余图照这三点对位。`cat_bust` 现在几乎能与 `f_bust` 重合，可以硬切；`boy_bust` / `man_bust` 现在需要缩放 0.89 / 0.873 才能对上，换图时**请直接画成能重合的尺寸**（渲染器里的 `REGISTER` 表就是为这三次校正存在的，能删掉最好）。
7. **分墨层（可选但很加分）**：如果能交三张同尺寸的分墨 PNG（`<name>_cream.png` / `_orange.png` / `_black.png`，各自只有该墨的 alpha）或一个分层的 PSD，载入时的自动分色就可以省掉，错版（套印不准）特效也会更干净。不给也不影响使用。

> **只收位图，不收矢量。** SVG 通道 2026-11-17 已关闭（理由与实测见 `docs/archive/剪影-试验线记录.md` 的 SVG 结案）：交付按 PNG（≥2× 设计基准）或分层 PSD，比例与配准见上一条。

## 五、交付流程

1. 照第二节做图，文件名按第三节（覆盖）或第四节的建议名（新增）。
2. 放进 `assets/character/`。
3. 跑 `node tools/art_check.mjs`：它会逐张量尺寸、留白、alpha、三墨，并和 `docs/archive/v4/art/baseline.json` 比构图位移；加 `--strict` 时规格不符即返回非零。
4. 跑 `node export/export.mjs --sheet out/art_<name>.png --times <歌时间> --cols 1 --width 1280 --height 720`，看真实构图下的效果（这一步是肉眼验收）。
5. 同组配准若需要缩放/位移，把每张的「相对原图位移」读数一并给我，我来改 `src/engine/art.js` 的 `REGISTER`。

**注意**：`REGISTER` 里的位移是**源像素**（以 1086 宽的 `f_bust` 为基准），换更高的分辨率后要按「新图宽 / 1086」换算，这一条由接管方处理。

## 六、验收清单

脚本自动查：`node tools/art_dims.mjs`（源尺寸 / 设计基准 / `sx`、`sy` 是否相等 / 长宽比偏差 / 载入告警），`node tools/art_check.mjs`（文件是否存在、是否可解码、长边是否达标、四边留白、alpha 构成（残点 / 半透明 / 主体是否 255）、三墨偏差与「三墨以外的实体像素占比」、相对原图的构图位移与尺度差）。矢量交付时第二条要加 `--svg <目录>`。

## 七、七阶（三墨不够用时的合法变体）

"颜色不够用"是这套素材的真实短板：三墨会把皮肤、衣料、盔甲并成同一块。引擎已经扩到**七阶**——三墨仍是主口径，七阶是**有条件的备选**。

**七阶表**（浅 → 深；三墨 = 第 0 / 3 / 5 阶，所以三墨图天然是七阶的子集）：

| 阶 | 族 | 值 | 说明 |
| --- | --- | --- | --- |
| 0 | cream | `#f4e0c6` (244,224,198) | 米白主体 |
| 1 | cream | `#d9bb98` (217,187,152) | 米白暗面 |
| 2 | orange | `#f09060` (240,144,96) | 橙亮面 |
| 3 | orange | `#dc723f` (220,114,63) | 橙主体 |
| 4 | orange | `#8f3a1e` (143,58,30) | 橙深面 |
| 5 | black | `#241a15` (36,26,21) | 黑主体 |
| 6 | black | `#141010` (20,16,13) | 黑更深 |

**规矩**（第 1–3、5–6 节全部照旧，只换第 4 节）：

- 只许这七个值，**每通道 ±12**；不许渐变、不许第八个色、不许半透明。
- 阶的分配要跟"族"一致：亮面用 0/2/3，暗面用 1/4/6，**不要用亮阶画阴影**（那会让画面翻起来）。
- 三墨能给就三墨。七阶是为了"画不出来但能过滤镜"这条退路存在的。

**引擎怎么认**：`tools/art_check.mjs` 会量出 `N 阶`（`palette` 字段；3 = 三墨，7 = 七阶，中间值说明有阶没填满），`outsidePct7` 应为 0。渲染端 `src/engine/art.js` 按"族内分阶"分版，`figure()` 自动叠暗面（`shades:false` 可关）；明暗阶走位图掩膜，三墨的路径轮廓不受影响。

### 7.1 一条硬约束：三墨源过滤镜还是三墨

滤镜只是**减色**，不会造色。已经合规的三墨原图再过一遍 `art_filter --levels 7`，出来的还是三墨——**七阶必须有多色源**：要么新画，要么拿 Live2D 渲图这类"本来就有几十种颜色"的图去压。

三条边界（写清楚，免得以后误用）：

1. `fit` 只认外框，不认姿势。同一 key 换了姿势，`regions.json` 的关键点必须人工重标。
2. `--snap` 是硬边化：把颜色吸到最近的墨，画面会变硬；插画类输入用它救急可以，当定稿不行。
3. `art_check` 的「留白 <5%」提醒对本片不适用——这部片子本来就是满幅裁切构图，
   验收只看 `结果: 通过` 与位移/尺度两列。

## 九、层次：纯剪影之后的三条路（2026-11-17）

阁下问了一句要紧的：**纯色剪影真的没有层次吗？** 答案是没有——它只有一个面，内部信息全在 alpha 里，天生零层。
要有层次只有三个来源，实测结果：

| 来源 | 做法 | 实测 |
| --- | --- | --- |
| 手工双层 | `--core cream --inset 40`：外形一墨、内芯一墨、包住的空隙填黑 | 成了一道"描边式"的环，像贴纸，**是假层次** |
| 模型自身图层 | `--only hair` / `--hide`：按 `PARTS_01_HAIR_FRONT_001`、`FACE_001` 这类命名分开渲 | **失败**：`setPartOpacityById` 设完被引擎在 draw 前重算回去；drawable 与 part 的映射没有暴露（要动 moc3），暂不做 |
| 大形化三墨 | `--median r`：对墨标号做邻域投票，把边界推成连续大块面，再 `--keyline` 压线 | **可用**：橙发、米白脸/领、黑衣与空脸三块面立住了，没有碎斑 |

### 推荐配方（1086×1448 交付尺寸）

```powershell
node tools/live2d_art.mjs ink --in out/_lib/p_face.png --out out/_lib/f_bust.png `
  --w 1086 --h 1448 --crop 1544,378,1266,1688 `
  --median 6 --clean 2 --island 6000 --keyline 5 --blue 0.005 `
  --erase "650,780,140,120;515,995,100,70"
```

- `--median r` 是**大形化**：与 `--island`（按面积砍小块）职责不同，一个投票、一个砍块，两者一起用才干净。
- `--keyline 5` 把三块面重新画出线，平涂感才回来（线宽与 `--stroke` 同口径，按输出 px）。
- 三墨占比参考：cream 20.6% / orange 59.6% / black 19.8%，与原片接近。
- 这条等于「B 的语言 + 三墨的层次」：外形是剪影，内部只剩三块面，形态仍由模型决定。

### 边界（别越）

- 它是**处理**，不是设计；做得再干净也到不了画师画的那版（`踩坑与经验.md` 3.13）。
- `--median` 会把小细节整片吃掉（花饰、缎带、胸针都会没），要留哪个得用 `--erase` 之外的手工层补。
- 定位：进片占位 / 灰盒可看，发布前仍要换手绘版。
