# 上游文档登记

这个工程是上游仓库 **world.execute-me-lyric-mv**（第四版，约 4.0 分发）的简体中文二创副本。上游把「制作者给 AI 的全部要求」公开在仓库里，这些文档在副本里**原样保留、一字未改**（我们只改 UI 与对话文案、字体、导出参数，不碰脚本与歌词语义）。

这份登记解决三件事：**哪些文件是上游的**、**它们在副本里的位置**、**动过没有**。要改其中任何一份，先来这里改登记。

## 三、版权与引用

- 这些文档的著作权属上游制作者。上游 README 的原话大意：**只用提示词、配自己的画面**没有硬性法律要求，只请在成片与仓库里注明来源并链回原视频与原仓库；**整段转载文档全文**要保留版权与出处。
- 本副本对它们的处理是「留存 + 引用」，没有再分发用途；仓库默认 private。
- 引用格式（本副本采用）：

  > 原作：world.execute (me) ; — Mili；MV 引擎与文档：world.execute-me-lyric-mv（第四版）；本作为简体中文二创副本。

## 四、和本副本的关系（该读哪份）

- **要改片子的叙事/视觉规则**：以上游 `PLAN.md`、`KIT.md` 为准，`PROMPT_v4.md` 优先于它们。
- **要改简体中文文案**：看 `二次创作\文稿\台词中文稿.md` 与 `docs/archive/v4/chat_script.json`，别去动 PROMPT。
- **要改剪影/美术交付**：看 `二次创作\说明\剪影规格.md`（含第七、九、十、十一节的实测结论）。
- **要知道踩过哪些坑**：看 `二次创作\说明\踩坑与经验.md`。
