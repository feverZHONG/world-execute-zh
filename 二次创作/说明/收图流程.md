# 收图流程 — 阁下的图到了之后，怎么上片

这一页只讲一件事：**八张剪影怎么从「随便一张图」变成「能进片的那张图」**。
片子里的数全都长在 1086×1448（`f_eye` 1254×1254）这套设计基准上——`regions.json` 的关键点、
场景里的裁切框、`art.js` 的 `REGISTER` 位移。所以换图不是把文件替换掉就完事：
**构图要先回到基准，画得好不好是第二步**。

工具：`tools/art_intake.py`（Python + Pillow，不需要另装东西）。

---

## 一、四条命令

```powershell
# 1) 规整 + 量墨 + 出报告（只写 assets/_intake，不动正式素材）
python tools/art_intake.py --src "<收图目录>"

# 2) 图不是严格三墨（有别的颜色）就加 --snap，把颜色吸到最近的墨
python tools/art_intake.py --src "<收图目录>" --snap

# 3) 看进片效果（同一秒，新图 vs 现在这套并排对比）
python tools/art_intake.py --src "<收图目录>" --preview 20,66.5,124.9,166.5,170.2

# 4) 定了就装库（原图自动备份到 assets/character_prev/）
python tools/art_intake.py --src "<收图目录>" --install
```

装库之后**一定要**再跑一遍独立验收，两个工具口径不同，互相能咬出问题：

```powershell
node tools/art_check.mjs            # 对基线看构图差、尺寸、留白
```

## 二、交什么图（清单）

命名就是 `<key>.png`，八张的 key 固定；**只交其中几张也行**，没交的保持原样。

| key | 画面 | 画布 | 长边下限 | 被画布切掉的一边 |
|---|---|---|---|---|
| `f_bust` | 正面胸像、无脸，全片的基准图 | 1086×1448 | 2000 | 无（四边都留白） |
| `f_profile` | 严格左侧脸、低头，只有额—鼻—唇—下巴的轮廓 | 1086×1448 | 2000 | 无 |
| `f_reach` | 一只手伸向观众、五指张开；另一只手按在胸前 | 1086×1448 | 3000 | **下边**（发梢伸出画布） |
| `f_eye` | 脸部特写，一只眼睁开；片中**永远镜像**使用 | 1254×1254 | 3000 | 上 / 下 / 右（满幅裁切） |
| `boy_bust` | 少年正面胸像、无脸 | 1086×1448 | 2000 | 无 |
| `man_bust` | 成年男子正面胸像、无脸（片中只作极淡的影） | 1086×1448 | 2000 | 无 |
| `cat_bust` | `f_bust` 加两只条纹猫耳 | 1086×1448 | 2000 | 无 |
| `cat_paws` | 猫耳，双拳举起来当爪子，尾巴在画面左侧 | 1086×1448 | 2000 | **上边**（耳尖顶到画布） |

格式：**PNG-24 带透明通道**，主体实心（alpha 255）、外面全透明。
不要白底、不要灰底、不要阴影、不要渐变；三墨走色请照 `剪影规格.md` 第一节：
米白 `#f4e0c6`、橙 `#dc723f`、近黑 `#241a15`（片中载入时会按 40 的半径归色，差一点没关系，别差太多）。

## 三、关键点（构图要落在哪）

规整只保证**主体的外框**落到基线的位置上；片子内部的动作（眨眼、胸针发光、花饰转、手伸出来）
靠的是 `regions.json` 里的关键点。交图时照着这几个位置画，`regions.json` 一个数都不用改：

| key | 下巴 chin | 花饰 flower（中心） | 胸针 brooch | 其他 |
|---|---|---|---|---|
| `f_bust` | (52.6%, 43.4%) | (70.0%, 15.0%)，直径约 11% 宽 | (52.9%, 55.0%) | 披肩角约 (20%, 56%) / (87%, 57%) |
| `f_profile` | (39.7%, 48.7%) | (64.8%, 17.4%) | (50.5%, 62.4%) | 鼻尖 (28.9%, 40.6%) |
| `f_reach` | (57.8%, 36.7%) | (70.9%, 12.3%) | — | 左下手掌 (26.7%, 76.0%)；胸前手 (72.7%, 52.5%)；眼 (59.9%, 22.8%) |
| `f_eye` | (51.8%, 71.8%) | (78.0%, 22.7%) | — | 睁开的眼 (58.2%, 41.6%)；嘴 (47.8%, 62.6%) |
| `boy_bust` | (52.5%, 50.0%) | (72.9%, 18.4%) | (53.3%, 61.4%) | — |
| `man_bust` | (52.5%, 50.2%) | — | (51.8%, 62.6%) | — |
| `cat_bust` | (55.2%, 46.8%) | — | (55.2%, 58.1%) | 双耳各约 11% 宽、13% 高的竖椭圆 |
| `cat_paws` | — | (73.8%, 18.2%) | (63.4%, 52.8%) | 双眼 / 双爪 / 尾巴见 `regions.json` |

括号里是**设计基准画布上的百分比**（x, y，左上角为原点）。
`boy_bust` / `man_bust` / `cat_bust` 还额外挂了 `REGISTER`（相对 `f_bust` 的缩放与位移），
`cat_bust` 的位移是 (-28, -49)：它和 `f_bust` 几乎重合，耳朵是唯一的新东西。

## 四、报告怎么读

每张一行，四段：

```
f_profile  1400x1800 → 2172x2896  墨 3 阶 · 墨外 1.59% · 构图差 cx +0.002 cy -0.006 fw -0.034 fh -0.033  [ok]
```

- `→` 左边是原图尺寸，右边是交付尺寸（按 2 倍基准出；`f_eye` / `f_reach` 自动加到长边 3000）
- `墨 N 阶`：文件里实际用了几阶墨（3 = 严格三墨，7 = 七阶，超出或不足要看一眼）
- `墨外 x%`：实心像素里有多少不在三墨/七阶上（就是「第四种颜色」）
- `构图差 cx / cy / fw / fh`：主体外框相对基线的中心偏移与宽高比偏差，**超过 ±0.05 会标 `偏差大`**
- `[ok]` / `[偏差大]`：只看外框，不看画

报告落在 `out/art_intake.json`，每张还带 `input`（原图长什么样）和 `register`（三张要配准的图给出机械初值）。

三种常见情况：

| 情况 | 表现 | 怎么办 |
|---|---|---|
| 图是严格三墨、构图也正 | 墨 3 阶、墨外 0–2%、构图差 < 0.01 | 直接 `--install`，装库后跑 `art_check` |
| 图是插画/有别的颜色 | 墨外 > 5% 或墨 5–7 阶 | 加 `--snap`（硬边化）；Snap 后仍难看，就退回画 |
| 图构图漂了（缩了 / 偏了） | 构图差大，但`墨`正常 | `--mode fit`（默认）会自动归位；别用 `asis` |

`--mode asis` 只缩放不动构图：**只在阁下已经按基准排好版时用**，否则一定会偏。

## 五、装库之后的三步

1. **构图验收**：`node tools/art_check.mjs`，看「位移 / 尺度」两列；`结果: 通过` 就行。
   （它报的「留白 < 5%」提醒对本片不适用：这部片子本来就是满幅裁切构图，5% 只是「重画时」的建议。）
2. **配准复核**：`boy_bust` / `man_bust` / `cat_bust` 的 `REGISTER`。报告里的 `register` 是**机械初值**，
   只对「同一个姿势换个画法」有效；换了姿势必须拿下巴 / 花饰 / 胸针三点在画面里对一遍
   （`--preview` 出静帧，肉眼比）。
3. **全片回归**：`node export/export.mjs --sheet out/qa_replace.png --times 20,66.5,124.9,166.5,170.2 ...`
   确认没有露馅的裁切，再决定要不要重出母版。

## 六、边界（这套工具**不能**替你做的）

- 它不判断画得像不像、好不好看，只保证位置、通道、墨阶、尺寸对。
- `fit` 认的是**主体外框**，不是姿势。同一个 key 换了姿势（比如 `f_reach` 的手换了方向），
  `regions.json` 的关键点必须人工重标，工具不会替你想。
- 换图后如果主体比例和原图差得多（比如把 1:1 的头塞进 3:4 的框），`fit` 会等比缩放，
  结果可能出现「头被缩得太小」——这种情况退回给图，不要靠工具硬拉。
- **本工作区禁止用生图工具出图**（2026-11-17 阁下定）：八张只能由阁下/画师给。
  本仓库只做收图、归位、验收、接线。
