## 一、引擎要几张

八张，文件名固定，少一张页面就起不来（`src/engine/art.js:29` 写死了这八个名字）：

| 文件名 | 是什么 |
|:--|:--|
| `f_bust.png` | 她的半身，正脸。**全片的基准图**，其他角色要对齐到它 |
| `f_profile.png` | 她的侧脸 |
| `f_reach.png` | 她伸手 |
| `f_eye.png` | 眼睛特写 |
| `boy_bust.png` | 男孩半身 |
| `man_bust.png` | 男人半身 |
| `cat_bust.png` | 猫半身 |
| `cat_paws.png` | 猫爪 |

各自画什么、在原片里怎么用，看 `docs/v4/PLAN.md §4`。原图在 `assets/character/`，可以先照着看。

## 二、硬规格（照着来，不合规就出鬼）

1. **PNG + alpha 透明背景**。引擎按 alpha 切形状，实体会被强制成不透明。alpha 低于 16 的算灰尘（会顺手把杂边去掉）。
2. **三墨色**，就三种，不要渐变不要照片色：

   | 墨 | 大致值 |
   |:--|:--|
   | 奶油 `cream` | `#F4E0C6`（244, 224, 198） |
   | 橙 `orange` | `#DC723F`（220, 114, 63） |
   | 黑 `black` | `#241A15`（36, 26, 21） |

   引擎加载时按中位数再校准一次，但你给的越干净，分离越准。印刷顺序固定：奶油 → 橙 → 黑。
3. **尺寸**参考 `f_bust`：1086×1448。其余图按同一场景内的比例画，别一张 4K 一张 720。
4. 画的是**剪影/平涂**，不是写实插画。引擎会自己描边、矢量重绘、做半调与字符屏。

## 三、还要给一份 `regions.json`

`assets/character/regions.json` 里每张图有一组部位坐标，引擎靠它裁脸、定位花、胸针、下巴、构图：

```json
"f_bust": {
  "alpha": true,
  "size": [1086, 1448],
  "face":  [367, 259, 313, 369],
  "chin":  [571, 628],
  "flower":[760, 217, 60],
  "brooch":[574, 797, 34],
  "figure":[6, 17, 1077, 1423],
  "crops": { "avatar": [330, 60, 560, 560], ... }
}
```

**换图就要重标这份表**，这是整个美术环节最费工夫的一步，比画图本身还慢。标错不会报错，只会画面歪——所以每换一张就出单帧看一眼。

## 四、对位表

`src/engine/art.js:44` 有一张 `REGISTER`：

```js
const REGISTER = { cat_bust: [1.0, -28, -49], boy_bust: [0.89, 60, -18], man_bust: [0.873, 81, -4] };
```

它是把其他角色缩放平移到 `f_bust` 上（下巴、花、领口对齐）的手测参数。新角色换掉之后这张表要重新量，否则换角色镜头会跳。
