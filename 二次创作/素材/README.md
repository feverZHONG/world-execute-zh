## 与根目录 `素材箱/` 的关系（2026-11-20 整理）

根目录还有一份 `素材箱/`（参考 / 美术 / 配色 / 台词 / 音乐，各一份 `说明.md`），写于 2026-11-16、整目录 gitignore、**不入库**。两份是同一件事的两次尝试，自本日起以本目录为准：

## 规矩

- 这里的图**不进渲染**：引擎只读 `assets/character/`（八张 + `regions.json`），别指望把图丢进这里就生效。
- 真要进片子的：图放 `assets/character/`，规格照 `角色/README.md`，换完先跑 `node tools/art_dims.mjs` 确认 `sx == sy`，再 `node tools/art_check.mjs` 对基线。
- 命名带出处：`参考-XXX-来源.png`，将来找得到。
