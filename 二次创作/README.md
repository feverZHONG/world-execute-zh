## 规矩

- **改副本，不改原目录**。原目录 `E:\DCIM\【视频】素材\world-execute-me-lyric-mv-main` 是干净原始件。
- `node_modules` 是指向原目录的目录链接，原目录动了这份工程就废。
- 每一处改动，改完出单帧看一眼再往下走。这工程不报错的地方最容易歪。
- **动了任何中文，先 `node tools/zh_charset.mjs`，再 `--check` 看退出码**，然后才导出。
- **交付件分辨率下限是 1920×1080（1080p）**。要提速只能改帧的传输格式（`--frame jpeg`）或编码器，不许降 `--width/--height`；960×540 只用于诊断与小样。
- 换素材/换尺寸之前先读 `说明\踩坑与经验.md` 3.3：坐标基准已收进 `art.js` 的 `REF` 表；换完先跑 `node tools/art_dims.mjs` 看 `sx == sy`。
