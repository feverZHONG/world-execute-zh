## 每张从哪来

| 画板 | 用在哪 | 形体来源 |
|:--|:--|:--|
| `f_bust.png` | 她的胸像（主镜） | 她本人 Live2D `l2d16` 原生渲图 |
| `f_eye.png` | 眼部特写 | 同上，`--box 678,238,320,320` 放大 |
| `f_reach.png` | 伸手镜（片尾注视） | 同上 |
| `f_profile.png` | 侧脸 | `l2d5017` |
| `boy_bust.png` | 店长胸像 | `l2d01` |
| `man_bust.png` | 男体剪影 | `l2d19` |
| `cat_bust.png` | 猫（半身） | `l2d06` |
| `cat_paws.png` | 猫爪 | `l2d07` |

同名的 `.json` 是裁切参数与配准数据（`plate` 的取框、`face`/`chin` 的实测点），跟着图一起改；`raw.json` 是画板名册，`regions.json` 是场景里的裁切矩形。

## 想换图

1. 读规格：`二次创作/说明/剪影规格.md`（尺寸 1086×1448、三墨、边缘、透明底）。
2. 走流程：`二次创作/说明/收图流程.md`（`python tools/art_intake.py` 规整 → `node tools/art_check.mjs` 比基线 → `--preview` 出静帧）。
3. 换完跑 `npm run check:plates`，确认 PNG 是 RGBA 且透明占比 > 0.1%（否则进片是黑方块）。

不换也能公开、能跑、能转发——只要不商用。
