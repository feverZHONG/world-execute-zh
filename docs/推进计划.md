## 五、出片提速：只做对瓶颈的那一刀

| 帧怎么传 | 1080p60 全片 | 判据 |
|:--|:--|:--|
| `--frame raw`（RGBA 8.3 MB/帧） | 8.8 fps / 24.5 分钟 | `send` 受 ~90 MB/s 带宽限制 |
| `--frame jpeg --q 0.95`（0.48 MB/帧） | 22.6 fps / 9.6 分钟 | 那 28 ms 是浏览器每帧一次 JPEG 编码 |
| **`--frame h264`（页面内硬编，默认）** | **86–125 fps / 约 2.5 分钟** | 编码器在页面里，ffmpeg 只 `-c copy` |

根因与三次翻车见 `说明\踩坑与经验.md` 四节；探测器 `node tools\probe_webcodecs.mjs`。
